# Streamlit Chatbot

A minimal chatbot project built with Streamlit.

## Run locally

From this directory, activate the virtual environment and start the app:

```powershell
.\venv\Scripts\Activate.ps1
streamlit run chatbot-ai.py
```

Then open the local URL shown in the terminal, usually `http://localhost:8501`.

The current response is a local echo so the project runs without an API key. Replace
the response block in `chatbot-ai.py` with a model integration when you are ready.
